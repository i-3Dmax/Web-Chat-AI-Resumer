# vk-chat-resume

Userscript для выгрузки сообщений из бесед VK (`vk.ru`) и создания краткого резюме с помощью ИИ.

## Возможности

- загрузка выбранного количества последних сообщений;
- загрузка сообщений за выбранный период в днях;
- копирование выгруженных сообщений в буфер обмена;
- два режима резюме: «Все события» и «Только важные»;
- выбор ИИ-провайдера: Qwen Cloud, OpenRouter (free), OpenRouter (Nemotron 3 Ultra);
- запоминание выбранного провайдера;
- автоматический повтор запроса при слишком коротком ответе ИИ;
- копирование резюме вместе с заголовком;
- отображение периода, за который были выбраны сообщения;
- автоматическая проверка новых версий скрипта.

Кнопка `✨ Резюме чата` появляется только при открытой беседе VK.

## Установка

1. Установите менеджер userscript:
	- [Tampermonkey](https://www.tampermonkey.net/);
	- [Violentmonkey](https://violentmonkey.github.io/).
2. Откройте файл [vk-chat-resume.user.js](vk-chat-resume.user.js) в GitHub и нажмите **Raw**. Менеджер userscript предложит установить скрипт.
3. Подтвердите установку.
4. Перезагрузите страницу VK.

Для установки напрямую используйте [Raw-ссылку на скрипт](https://raw.githubusercontent.com/i-3Dmax/vk.ru-chat-resume/main/vk-chat-resume.user.js).

## Использование

1. Откройте VK и перейдите в нужную беседу. Поддерживаются адреса вида `/im/convo/123`.
2. Нажмите `✨ Резюме чата`.
3. Выберите способ загрузки:
	- последние сообщения и их количество;
	- сообщения за период в днях.
4. Дождитесь окончания загрузки (загружаются только текстовые данные).
5. Выберите тип резюме:
	- **Все события** — основные моменты переписки с активными участниками;
	- **Только важные** — только важные моменты без перечисления всех событий.
6. Выберите ИИ-провайдер в выпадающем списке.
7. После обработки результат появится в отдельном окне.

В окне результата доступны кнопки:
- **Копировать резюме** — копирует заголовок и резюме в буфер обмена;
- **Копировать сообщения** — копирует исходные сообщения;
- **Закрыть** — закрывает окно.

## ИИ-провайдеры

### Qwen Cloud

Бесплатный тир с ограниченным количеством обращений.

1. Зарегистрируйтесь на [qwencloud.com](https://qwencloud.com).
2. Перейдите на страницу API-ключей: https://home.qwencloud.com/api-keys
3. Создайте и скопируйте API-ключ (после закрытия окна ключ скопировать будет нельзя).

### OpenRouter

Доступ к бесплатным моделям ИИ (Llama, Gemma, Mistral и другие).

1. Зарегистрируйтесь на [openrouter.ai](https://openrouter.ai).
2. Перейдите в Settings → Keys.
3. Создайте API-ключ.

OpenRouter (free) и OpenRouter (Nemotron 3 Ultra) используют один и тот же API-ключ.

### Автоматическое управление ключами

- после успешного запроса ключ сохраняется в cookie текущего домена VK на один год;
- при следующих запусках ключ вводить не нужно;
- при ошибке авторизации (`401` или `403`) старый ключ удаляется и запрашивается новый;
- выбор провайдера запоминается между сессиями.

## Анонимизация

Перед отправкой переписки в ИИ скрипт заменяет имена авторов на псевдонимы вида `User0001`, `User0002` и так далее. Это помогает скрыть имена участников во время обработки текста ИИ.

- одинаковый автор получает один и тот же псевдоним в рамках одного запроса;
- анонимизируются имена авторов обычных сообщений и ответов на сообщения;
- после ответа ИИ псевдонимы заменяются обратно на исходные имена;
- ручное копирование исходных сообщений сохраняет оригинальные имена;
- текст сообщений и созданное резюме отправляются в ИИ для обработки;
- ни названия чатов, ни какие другие данные не передаются, только обезличенные тексты сообщений.

## Автоповтор

Если ИИ вернул слишком короткий ответ (1-2 строки), скрипт автоматически повторяет запрос (до 2 раз).
