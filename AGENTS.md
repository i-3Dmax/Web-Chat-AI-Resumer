# Инструкции для AI-агентов

## Назначение проекта

- Репозиторий содержит один самостоятельный userscript для VK (`vk.ru` и `vk.com`): экспорт истории беседы и краткое резюме через Qwen Cloud.
- Основная реализация находится в [vk-chat-resume.user.js](vk-chat-resume.user.js); краткая документация проекта — в [README.md](README.md).

## Структура и стиль

- Сохраняй userscript-метаданные в начале файла: `@match`, `@grant`, `@connect`, `@run-at` и `@noframes` должны соответствовать используемым API.
- Код обернут в IIFE с `'use strict'`; придерживайся существующего ES5-совместимого стиля с `var` и обычными `function` для совместимости с менеджерами userscript.
- Не добавляй зависимости, сборку или отдельный сервер без явной необходимости: скрипт устанавливается и запускается непосредственно менеджером userscript на странице VK.
- Не меняй публичные идентификаторы DOM, VK API-метод `messages.getHistory` или bridge между page context и userscript без проверки всех связанных обработчиков.

## Проверка изменений

- В проекте нет package manager-конфигурации, сборки и автоматических тестов. Перед сдачей проверь синтаксис измененного JavaScript доступным локальным инструментом, если он установлен.
- Основная проверка выполняется вручную в Tampermonkey/Violentmonkey на URL `https://vk.ru/` или `https://vk.com/`: открыть беседу `/im/convo/<id>`, запустить экспорт, проверить режим количества/периода, загрузку страниц, копирование текста и запрос резюме.
- Для изменений VK bridge отдельно проверь успешный ответ, ошибку API и тайм-аут; для Qwen отдельно проверь пустой/неверный ключ, ошибку HTTP и превышение лимита текста.
- Не записывай API-ключ в исходник, логи или документацию. Сохраняй существующий механизм запроса ключа через `prompt` и разрешенные `GM` API, если задача явно не требует другого.

## Рабочий процесс агента

- Делай минимальные изменения в [vk-chat-resume.user.js](vk-chat-resume.user.js), не форматируй несвязанные участки.
- При исправлении userscript показывай пользователю полный готовый файл, а не только фрагмент.
- Если автоматическая проверка невозможна, явно укажи это и перечисли выполненные ручные проверки.
